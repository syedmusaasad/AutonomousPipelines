# Implementer Rubric

Score 0-10 based on the deliverable.

1. Correctness (4 points): The patch/script accomplishes the requested task without syntax errors.
2. Robustness (2 points): Edge cases (like file missing, JSON parsing errors) are handled gracefully.
3. Ceremony (2 points): The patch format is valid and can be applied directly using standard tools.
4. Simplicity (2 points): The solution is straightforward and avoids unnecessary complexity.
