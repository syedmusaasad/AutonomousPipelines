# Fast-Worker Rubric

Score 0-10 based on the deliverable.

1. Correctness (4 points): The command performs exactly the requested operation.
2. Brevity (3 points): The solution is a concise one-liner as requested.
3. Standard Tooling (3 points): Relies on standard POSIX/Unix tools (grep, sed, jq, etc.) without requiring external dependencies unless specified.
